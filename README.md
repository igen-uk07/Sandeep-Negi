## 🚀 Featured Project

### 🔍 Velric — Static Binary Security Analyzer

An explainable static analysis tool for **PE and ELF binaries** designed to identify suspicious capabilities and behaviors without executing the target binary.

**Key Features:**
- PE and ELF structural analysis
- Capstone-based disassembly
- Entropy and packing indicators
- YARA rule scanning
- Import and string-based capability detection
- Behavioral correlation and risk scoring
- MITRE ATT&CK technique mapping
